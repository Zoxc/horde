Use `cargo rustc --release -- --cfg code` to generate code examples for inspection.

Use `cargo miri test --target x86_64-unknown-linux-gnu` to run Miri on non-Linux targets.

Run
    - `cargo fuzz run sync_table`
    - `cargo fuzz run sync_table_drop`
    - `cargo fuzz run sync_table_concurrent`
    - `cargo fuzz run --build-std -s thread sync_table_concurrent`
in the `fuzz` folder to start fuzzing. It uses https://github.com/rust-fuzz/cargo-fuzz
